# Quick Start
1. Extract ZIP and open it in VS Code.
2. Command Prompt terminal:
```cmd
npm install
npm run install:all
copy server\.env.example server\.env
npm run dev
```
3. Open http://localhost:5173.
4. Register/login, create a room, then join from another browser window.
5. Test video, mute/camera, screen share, chat, encrypted file sharing and whiteboard.
